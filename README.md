# Last Circle

A wave-survival arena game: hold the circle, build element combos, survive the endless waves.

**Play:** https://darkz94.github.io/last-circle/

Install on a phone from that link: Android Chrome → ⋮ → *Install app*; iPhone Safari → Share → *Add to Home Screen*.

When updating `index.html`, bump `VERSION` in `sw.js` so installed copies refresh.
